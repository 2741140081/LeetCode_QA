这就导致一开始可能只能 20张图片在容器中, 高度是 h1,
这一步计算比例, 使用的是 items.size(), 即所有图片来计算高度, 这就导致出现问题, 即实际滚动一个小的距离, 但是方法会返回一个大的滚动.

/**
 * 获取当前可见的图片索引
 * @return 当前可见的图片索引
 */
public int getCurrentVisibleIndex() {
    // 获取滚动条的归一化比例值
    double scrollRatio = getScrollTop();
    ObservableList<String> items = getItems();
    if (items == null || items.isEmpty()) {
        return 0;
    }

    double estimatedCellHeight = estimateCellHeight();
    if (estimatedCellHeight <= 0) {
        return 0;
    }

    // 转换为实际滚动的像素偏移量：比例 * 总内容像素高度（总条目数 * 单格预估高度）
    double totalContentHeight = items.size() * estimatedCellHeight;
    double actualScrollYPixel = scrollRatio * (totalContentHeight - this.getHeight());

    int estimatedIndex = (int) (actualScrollYPixel / estimatedCellHeight);
    // 边界约束保证索引合法
    return Math.max(0, Math.min(estimatedIndex, items.size() - 1));
}
